   - ⚡ **Double Click**: Ring + Thumb pinch for instantaneous double clicks.
   - 📜 **2-Finger Inertial Scrolling**: Raise Index + Middle fingers together (Peace sign ✌️) and slide vertically for buttery-smooth page scrolling.

   - 🎨 **Air Canvas Holographic Draw Mode**: Switch into 3D Air Painting mode (`M` key) and paint with neon lasers (Cyan, Emerald, Magenta, Amber, Laser Red) directly on screen!

## 🎮 Spatial Gesture & Keyboard Controls Cheat Sheet

### In `mouse.py` (Neural Master X):

| Gesture / Key | Action |
| :--- | :--- |
| **Index Fingertip** | Moves mouse cursor smoothly across desktop |
| **Thumb + Index Pinch** | Left Click (or Hold to Drag & Drop) |
| **Thumb + Middle Pinch** | Right Click |
| **Thumb + Ring Pinch** | Double Click |
| **2 Fingers Up (✌️)** | Smooth Inertial Scroll (Move up/down) |
| **Thumb + Pinky Pinch** | Volume Dial (Move up for Volume Up, down for Volume Down) |

| `SPACE` | Capture High-Resolution Snapshot to `Screenshots/` |
| `ESC` / `Q` | Exit Application |
